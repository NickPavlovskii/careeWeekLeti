# 🎓 Карьерная неделя — веб-приложение

Веб-сайт для проведения **Карьерной недели** — мероприятия, объединяющего студентов и компании.  
Приложение позволяет студентам регистрироваться на события, просматривать программу, участников и спонсоров,  
а компаниям — представлять свои вакансии и участвовать в программе мероприятия.

---

## 🌐 Основные возможности

- 🧑‍🎓 Регистрация студентов и участников  
- 🏢 Регистрация компаний и спонсоров  
- 🗓️ Просмотр программы мероприятий  
- 📍 Информация о месте и времени проведения  
- 💬 Форма обратной связи и контакты организаторов  
- 📸 Галерея или медиараздел (опционально)

---

## ⚙️ Технологии

- **Vue 3** — основной фреймворк  
- **Vite** — быстрый инструмент сборки  
- **TypeScript** — типизация  
- **Vue Router** — маршрутизация по страницам  
- **Pinia** — управление состоянием  
- **Axios** — работа с API  
- **TailwindCSS / SCSS** *(по проекту)* — стилизация
